[[CORE]]

- glass/beerbottle + rag = molotow cocktail
- glass/beerbottle + wall = Bottleknife/Shard
- emptying gasoline from bottles leaves puddles
- shard + rag = shardknife
- nails + planks = sketchboard ( sketch storage )
- rope + tarp or pelts = courier bags -> vanilla and HunterZ
- courier bags + sticks = improvised backpacks -> vanilla and HunterZ
- camonet/tarp/garbage bags are placeable as a stache
- guts + knife = gutrope / cable reel + knife = cable rope
- knot gutrope in hands = gut belt
- motorbike helmets + nails/scrapmetal = yellowking helmets
- clothing + waterproofer = waterproofed clothing
- combining any scrapmetal / fabric / rifleparts to receive a craft box ( material storage you can craft from )
- paper folded in hands = paper mask
- tarp/garbage bag + knife = rainproof poncho
- tarp/garbagebag + long wooden stick = improvised umbrella
- magnifying scopes/binocular/reading glasses + tool = lens ( only if Armors and/or Weapons Addon )
- foodcan + rock = opened foodcan
- sketchbook ( none craftable storage for sketches )
- chainsaw ( none craftable saw )
- multitool ( none craftable knife/lockpick/screwdriver/saw/can opener)
- cutter ( none craftable knife )
- umbrella ( none craftable rainproof )
- military ponchos ( none craftable rainproof )
- valuables ( none craftable, usefull as currency )

[[AIRBRUSHING]]

- paintable: pants, masks, hats, tops, shoes, gloves, helmets, vests, rifles, pistols, backpacks, barrels, tents, protectorcase, waterproofbag, wooden crate, seachest, first aid kit, pouches, holster, firefighter axe, armbands, flags, ghillies


[[BUSHCRAFTING]]

Get plant fibre from harvesting plants and get stones by digging them up
- diggin stones has a chance to give flint; combine with knife for firestarterkit
- 5 bolts can be placed as a spike trap & covered with plant material || with optional Terje Skillmod from BC LVL 5
- pelts can be placed ( also human skin if gore addon is installed ) -> vanilla and HunterZ
- pelts + knife = neckwarmer ( also human skin if goreaddon is installed ) -> vanilla and HunterZ || with optional Terje Skillmod from BC LVL 1
- trophies from skinning various animals
- some trophies + rags/fabric = wearable trophies ( also skull if goreaddon is installed ) || with optional Terje Skillmod from BC LVL 1
- goathorn + tool = drinkinghorn || with optional Terje Skillmod from BC LVL 2
- bear skull & pig head are naturally wearable
- big stone + hammerish tool = firebowl
- plant matrial + netting = plant ghillie || with optional Terje Skillmod from BC LVL 2
- bones + knife = bone needles, bone awl or carved hipbone || with optional Terje Skillmod from BC LVL 1
- bark or plant material + knife = plant fibre || with optional Terje Skillmod from BC LVL 1
- dark bark + water = bark paste || with optional Terje Skillmod from BC LVL 4
- bark paste + pelt = tanned leather || with optional Terje Skillmod from BC LVL 4
- tanned Leather + leather sewingkit = leather clothing || with optional Terje Skillmod from BC LVL 4
- fibre + bone needles = improvised sewingkit || with optional Terje Skillmod from BC LVL 1
- improvised sewingkit + bone awl = improvised leather sewingkit || with optional Terje Skillmod from BC LVL 1
- plant fibre in hands = rag || with optional Terje Skillmod from BC LVL 2
- plant fibre in hands = fibre rope || with optional Terje Skillmod from BC LVL 2
- fibre rope in hands = fibre belt || with optional Terje Skillmod from BC LVL 2
- rope + wooden sticks + stone + bone = bushcraft kit || with optional Terje Skillmod from BC LVL 1
- treestump + tool = hollowed treestump stache || with optional Terje Skillmod from BC LVL 5
- bushcraft kit + sharp tool = improvised hammer / hatchets / shovels / spears / bolts / slingshot / bow || with optional Terje Skillmod from varying BC LVL
- short stick + rope = slingshot ( ammo = small stones ) || with optional Terje Skillmod from BC LVL 4
- long stick + rope = bow ( ammo = crossbow bolts ) || with optional Terje Skillmod from BC LVL 4
- plantmaterial in hands = leafcrowns ( seasondependent ) || with optional Terje Skillmod from BC LVL 2
- rope/gutrope/fibrerope/cablerope + small sticks = snaretrap
- big stone + tool = firebowl
- fill glass jars with water, vegtables, meat and mushrooms, then cook = conserved food


[[GORE]]

Get human heads, skin and infected meat by skinning zombies or humans
- human head + various Tools = skull pendant ( for holster slot/spike/trophyboard ), face skin, ear
- human face + burlapsack = zombie mask ( hides you from zombies when hands free, not running and not to close )
- firewood + knife = wooden head
- head + long stick = impaled head
- human skin + knife = skincape ( if bushcrafting installed )
- human skin + leather sewingkit = skintop/pants
- chainsaw + unconcious or tied up players = skin and quater alive
- blowtorch/grinder + scrapmetal = cage

[[SCRAPMETAL]]

Get scrapmetal by useing a sharp tool to disassemble
metalplates, barrels, guns, metal tools, generators, car doors & other stuff.
- angle grinder( not craftable, powerpack rechargeable with battery charger )
- scrapmetal + blowtorch/angle grinder = sledgehammer, axe, knife, lamp,
foldable hatchet/shovel, barrel, tripod, firepit, gasoline canister, pliers, gardenpot, barrel, metalcrate, metalplates, visor, mask, pocketheater
- scrapmetal + pliers / screwdriver = nails, wire, mess tin, barbedwire, adjustable buttstock/handguard, crossbow bolt, chemreflector, fishinghook
- scrapmetal + wooden plank = playable banjo


[[SEWING]]

Get fabric by folding a stack of rags or tarp in your hands.
- fabric + sewingkit = medical-, grenade-, universal-, platecarrier pouches, knife sheath,
plain armbands/flags, backbag, holster, carrying strap, chestbag, armpouch, cape
- fabric + waterproofing spray = tarp
- fabric + knife = netting
- camonet + knife = camonet cloak/gunwrap
- rope + fishinghook = improvised sewingkit


[[SIGNS & CANVAS]]

You can paint signs, canvases & orgasign with spraycans.
- planks + nails = plain signs, plain canvas, plain orgasign
- planks + nails = trophyboard ( takes wolfhead, bearskull, tusks, horns, antlers, foxtail, rabbithead, pighead, skull, featherhat, heads )

[[MEDICAL]]

- knife + zombie heads = spinal cord
- spinal cord + any mushroom = antibiotic (single use)
- fabric + sewingkit = improvised bandage ( only if sewing addon installed )
- burned out fires + knife = charcoal (single use)
- scrapmetal + various tools = splint
Gather herbs from meadow with bare hands, herbs can be directly consumed for one-time-effect
- nm_Herbs_atropabelladonna & nm_Herbs_digitalisgrandiflora = lethal Herbs
- nm_Herbs_urtica = vitamins
- nm_Herbs_matricaria = painkiller

[[NBC SUIT]]

- tarp + duct tape = improvised NBC suit
- craftbox(scrapmetal + fabric) + duct tape = improvised gasmask
- craftbox(scrapmetal + fabric) + blowtorch = NBC helmet -> only if armors addon is also installed


[[ARMORS]]

- rubber + sharp tool = earplugs
- rubber + leather sewingkit = sandals
- lens + scrapmetal = goggles
- craftbox(scrapmetal + fabric) + blowtorch = makeshift Helmet, Carrier Rig
- craftbox(scrapmetal + fabric + rubber) + blowtorch = makeshift vest-, arm-, hand-, leg-, feet armor
- craftbox(scrapmetal + fabric) + any vanilla vest = reinforced vest
- craftbox(scrapmetal + fabric) + any vanilla helmet = reinforced helmet
- exoparts + craftbox(scrapmetal + fabric) = exokit ; exokit + blowtorch/angle grinder = exosuit
-> Note: exoparts do not spawn naturally but can be added separatly: github/NCPR


[[WEAPONS]]

- nailgun ( not craftable )
- rope/gut rope/fibre rope + small sticks = tripwire
- place barbed wire to use it as trap
- wooden plank + nails = nailboard ( ruins car tires )
- fabric + suppressor = reinforced suppressor
- scrapmetal + short sticks or bolts = scrapmetal bolt for crossbows
- bolts + HE grenades = explosive bolts
- explosive bolts + gasoline = incendiary bolts
- bolts + chemgasgreandes = chemgas bolts
- bolts + chicken = chickenbolt ( no sketch/easteregg )
- scrapmetal + blunt weapon = improved weapon
- scrapmetal + blowtorch/angle grinder = beartrap, sword, silencer, caltrop
- scrapmetal + sharp tool = ammo for scrap cannon, bear trap, universal scope
- universal scope + lens = universal scope with magnification
- sharp tool + rifles = rifle parts
- craftbox(scrapmetal + rifleparts) + blowtorch/angle grinder = multiple makeshift firearms / flamethrower mag
- nailgun + knife = nailgun parts/mag
- craftbox(scrap + rifle parts + nailgun parts ) + blowtorch/angle grinder = nailrifle
- blown up prototype rifle + knife = railgun parts
- craftbox(scrapmetal + rifle parts + railgun parts ) + blowtorch/angle grinder = railgun ( needs a powerpack )
-> Note: blown up prototype rifle does not spawn naturally but can be added separatly: github/NCPR

- scrapmetal + gunpowder = improvised grenade ( does mainly shockdamage )
- improvised grenade + nails = improved grenade ( does mainly healthdamage )
- scrapmetal + projectile press ( small, mdium or large ) = small, mdium or large projectiles
- cartridge + fitting projectile + gunpowder assambled with pliers = bullets
-> Note: boxed cartridges & projectiles can be spawned via types.xml, found here: github/NCPR

[[VEHICLES]]

This addon allows the construction of a raft and a buggy
- set up a construction side with sticks and rope
- inspecting the discription text of the construction side gives further hints on crafting
- construction is only possible from outside the construction side
- Buggy Stage1: scrapmetal; Construction Tool: blowtorch/angle grinder
- Buggy Stage2: wooden planks, nails; Construction Tool: hammer
- Buggy Stage3: scrapmetal,flashlight, ducttape; Construction Tool: bare hands
- Buggy Stage4: scrapmetal, engine; Construction Tool: blowtorch/angle grinder
- Raft Stage1: scrapmetal; Construction Tool: blowtorch/angle grinder
- Raft Stage2: barrels, rope; Construction Tool: bare hands
- Raft Stage3: wooden planks & nails; Construction Tool: hammer
- Raft Stage4: scrapmetal, engine; Construction Tool: blowtorch/angle grinder
- power generator + tool = generator parts
- generator parts + scrapmetal = engine
- boat + tool = engine
- boat / any Wheel + tool = rubber
- rubber + scrapmetal = buggy wheel
- vanilla cars can be reinforced by putting scrapmetal into their invslot and using the blowtorch
- car armor / carrier can be repaired with a blowtorch
- car armor / carrier can be taken down with a crowbar
- vanilla cardoors + scrapmetal = reinforced cardoor
