KM_BetterFishing
Author: KM_Mods
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

CONFIG LOCATION:
$profile:KM_BetterFishing/KM_BetterFishing.json

FishType:
0 = Freshwater and Ocean
1 = Freshwater Only
2 = Ocean Only

Freshwater fish:
Carp, Bitterlings, SteelheadTrout, Fish_GrassCarp, Fish_Trout, Fish_Perch, Fish_Crucian, Fish_Crappie, Fish_Bluegill

Ocean fish:
Mackerel, Sardines, WalleyePollock, Fish_Pike, Fish_Zander, Fish_TunaFish, Fish_SwordFish, Fish_SilverBack

FishPreparation:
KnifeDamage = health removed from blade when preparing fish.
SpawnBones = true/false.
BoneCount = number of bone items spawned.
SpawnGuts = true/false.
GutCount = number of guts items spawned.
SpawnFishRoe = true/false.
FishRoeChance = percent chance to spawn roe when enabled.
FishRoeCount = number of roe items spawned.
BonesClassName / GutsClassName / FishRoeClassName = classnames spawned by preparation.
SalmonellaChance = percent chance added to fillets. 100 = always.
PreserveTemperature = prepared fillets/extras keep fish temperature.
PreserveFrozenState = prepared fillets/extras keep frozen state.
